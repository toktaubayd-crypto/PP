# ЗдоровоЕд — сайт по правильному питанию

Одностраничный сайт: тарифы (Стандарт / Премиум / VIP), разделы питания (безглютеновое, похудение, набор массы, АИП), расчёт калорий, подбор меню с учётом нелюбимых продуктов, списки «разрешено / запрещено / ограничить», кабинет клиента и панель владельца.

## Файлы
- `index.html` — весь сайт (HTML, стили и скрипт).
- `config.js` — цены, пакеты, скидки, ссылка на оплату, логин владельца.

## Как выложить на GitHub Pages
1. Создайте репозиторий на github.com и загрузите оба файла в корень (Add file → Upload files).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://ваш-логин.github.io/название-репозитория/`.

## Как поменять цены и пакеты
1. Откройте сайт, войдите как владелец: логин `admin`, пароль `admin123` (**сразу смените пароль**).
2. На вкладке «Админ» измените цены, состав пакетов, скидки, ссылку на оплату (https://…, например Kaspi Pay).
3. Нажмите «Сохранить и опубликовать»: скачается `config.js`. Замените им старый файл в репозитории — изменения увидят все.

Либо отредактируйте `config.js` прямо на GitHub (значок карандаша).

## Важные ограничения
- GitHub Pages — статический хостинг, серверной части нет. Аккаунты клиентов и заказы хранятся только в браузере клиента (localStorage) и вам недоступны.
- Вход владельца и клиентов — это защита интерфейса, а не настоящая безопасность: хэш пароля владельца лежит в `config.js` и виден всем. Не используйте здесь пароль, который применяете где-то ещё.
- Оплата не подтверждается автоматически: кнопка открывает вашу платёжную ссылку. Для реального контроля доступа нужен сервер и платёжный провайдер.
- Меню и списки продуктов справочные и не заменяют консультацию врача.
